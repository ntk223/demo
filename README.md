# Demo — Thuật toán cơ bản

Một đoạn code Python minh họa các thuật toán cơ bản kinh điển.

## Nội dung

| Nhóm | Thuật toán | Độ phức tạp |
|------|------------|-------------|
| Sắp xếp | Bubble Sort | O(n²) |
| Sắp xếp | Quick Sort | O(n log n) trung bình |
| Sắp xếp | Merge Sort | O(n log n), ổn định |
| Tìm kiếm | Linear Search | O(n) |
| Tìm kiếm | Binary Search | O(log n) — cần mảng đã sắp xếp |
| Khác | Kiểm tra số nguyên tố | O(√n) |

## Chạy thử

```bash
python algorithms.py
```
